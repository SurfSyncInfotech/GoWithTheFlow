//--------------------------------------------------------------------------------
SECTION: Global Constants and Debate Rules
//--------------------------------------------------------------------------------
This section defines the fundamental rules and configurations for debate:
- MARKERS defines the labels used on debate argument cards: "turn" (flipping an argument onto the opponent), "dropped" (conceding an argument by leaving it unanswered), "extend" (advancing an argument from an earlier speech), and "cross-apply" (applying an argument across contentions).
- SPEECHES and PF_SPEECH_ORDER define the official order and types of speeches in Public Forum debate (Constructive, Rebuttal, Summary, Final Focus, and Crossfire periods).
- PF_MIN_TIMES and PF_MAX_TIMES define the minimum and maximum permitted seconds for each speech duration in settings.
- JUMP_COLORS defines the color palette used for quick-jump contention indicators.
