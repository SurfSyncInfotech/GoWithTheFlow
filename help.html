Help

Pro Case starts at Pro’s opening speech and keeps every speech after it. Con Case starts at Con’s opening. Who speaks first changes that order for the whole round.

Add contention creates a named section. Type points inside it. Enter makes the next point box. Shift+Enter adds a line inside the same box.

A response lines up with the point it answers. If a point has several answers, later points move down.

The paperclip attaches evidence to the selected note, including a response. Paste from Google Docs or Word. The flow stays visible. Scrolling evidence does not change the selected note.

Columns focuses on a consecutive group of speeches. Show all restores that case. Export and print still include every speech.

Notes is for crossfire and reflections. Enter there is a normal line break.

The timer runs one speech, crossfire, or prep countdown. Prep time is separate for Pro and Con.

Rounds save in this browser. Export downloads a record. Version 1 does not import rounds. Clearing site data, private browsing, or another browser can remove the saved rounds.

Extend, Dropped, Turn, and Answered are labels you add yourself. The page does not decide them for you.
