GO WITH THE FLOW
Line-by-line reading of every source file
==========================================

How to use this file
--------------------
Line numbers match the files as they stand. A range such as 20-22 is one
statement that wraps. Blank lines and a lone closing brace are called out
once at the end of that function when they carry no extra meaning.

Scripts load in this order on every page:
  js/rounds.js, js/lineup.js, js/clean.js, js/save.js, js/helpers.js, js/app.js
Later files may call earlier ones. app.js is the only file that talks to the page.

There is no server. Opening index.html in a browser is the whole app.
Saved data lives in localStorage. Which round is open lives in sessionStorage.

js/helpers.js  (55 lines)
Small DOM helpers. No debate rules live here.
========================================================================

1-3   cloneTpl(id)
1     Declares the function. id is the id of a hidden template box in the HTML
      (sample-round, card-sample, and so on).
2     Finds that box, takes its first child element, and deep-clones it
      (cloneNode(true) copies the element and everything inside it).
      The original template stays in the page. The clone is what gets filled
      in and appended. Returns the clone.
3     End of function.

5-7   unhide(node)
5     Takes a DOM node.
6     If the node exists, removes the class "hide". page.css makes .hide
      display:none !important, so removing it shows the node.
7     End.

9-11  foldAway(node)
9     Takes a DOM node.
10    If it exists, adds class "hide", which hides it.
11    End.

13-16 clearNode(node)
13    Takes a parent node.
14    If there is no node, stop. Nothing to empty.
15    While the node still has a first child, remove that child. Repeats until
      the parent is empty. Used before redrawing a list so old cards do not stack.
16    End.

18-23 setLine(node, text)
18    Takes a node and a string.
19    If there is no node, stop.
20    Sets the node's text to text, or to an empty string if text is missing.
      textContent is plain text, so HTML in the string is not interpreted.
21    If text is truthy, show the node.
22    Otherwise hide it. Empty meta lines on a round card disappear.
23    End.

25-33 objList(box)
25    Turns an object whose values are the records (rounds, notes, preflows)
      into a plain array.
26    Starts an empty array.
27    Declares k, the loop variable.
28    If box is missing, return the empty array.
29    for-in walks every key on the object.
30    hasOwnProperty skips anything inherited from Object.prototype.
      Only the object's own values are pushed.
31    End of the if and the loop.
32    Returns the array of values. Order is the object's key order, not date order.
33    End.

35-43 joinSkipEmpty(parts, gap)
35    Joins an array of strings with gap, skipping blanks.
36    out starts empty.
37    i is the index.
38    Loop from the first part to the last.
39    If this part is empty, null, or undefined, skip it.
40    If out already has text, append gap then this part. Otherwise this part
      is the start, coerced to a string.
41    End of loop.
42    Returns the joined string. Used for "Tournament · Round 3 · vs North".
43    End.

45    Comment: home and preflow lists. ISO date strings sort correctly as text
      because they look like 2026-10-10T..., so a string compare is a date compare.

46-54 sortRecent(list)
46    Sorts a list in place, newest updatedAt first, and returns that same array.
47    Array.sort comparator.
48    x is a's updatedAt, or "" if missing.
49    y is b's updatedAt, or "".
50    If y is later than x, return 1, which puts b before a (newest first).
51    If y is earlier, return -1.
52    Equal dates stay tied (return 0).
53    End of comparator.
54    End of function. The closing of the file is line 55, a blank line.

js/save.js  (86 lines)
Read and write the one saved file in the browser.
========================================================================

1     STORE_KEY = "goWithTheFlow"
      The localStorage key for the live save.

2     BACKUP_KEY = "goWithTheFlowBackup"
      A second copy of the same JSON, written after the main key succeeds.

4-11  blankSave()
4     Builds a brand-new save when nothing is stored yet.
5     Returns an object.
6     rounds: empty object. Keys will be round ids.
7     preflows: empty object. Keys will be preflow ids.
8     settings: whatever startSettings() returns (font size, sound, clock times).
      startSettings is defined in rounds.js, which loads first.
9     lastRoundId: null until a round is saved from the workspace.
10    End of the object.
11    End of the function.

13-24 readSaved(key)
13    Reads one localStorage key and parses it. Returns the object or null.
14    try starts. JSON.parse throws if the string is cut off.
15    raw is the stored string, or null if that key was never written.
16    No string means there is no save. Return null. This is not an error.
17    Parse the string into data.
18    If parse produced null, a number, or a string, it is not a save. Return null.
19    Otherwise return the object.
20    catch runs when parse throws (truncated write, laptop died mid-save).
21    Comment: that broken string is not usable. The caller will try the backup.
22    Return null so openSave can fall through to the spare key.
23    End of catch.
24    End of function.

26-51 openSave()
26    Loads the save the app will actually use. Called once, at the top of app.js.
27    data is the main key, or null.
28    backup is the spare key, or null.
29    names will hold object keys.
30    i is a loop index.
31    If the main key is missing or unreadable:
32-34   and a backup exists, use the backup and set data.recovered = true.
        The home page reads that flag and shows the orange banner.
35-36   If neither exists, start from blankSave().
38    End of the missing-data branch.
39    If rounds is missing, put an empty object there so later code can index it.
40    Same for preflows.
41    If settings is missing, install the defaults.
42    Run the stored speech/prep lengths through mendClocks so a bad number
      cannot stay in the file. mendClocks is in rounds.js.
43    names = every round id.
44-47 For each round: mendRound repairs a broken shape, then stopTimerOnOpen
      freezes a clock that was still "running" when the tab last closed.
      A sleeping laptop must not keep burning prep.
48    names = every preflow id.
49    mendPreflow each one. Preflows have no timer.
50    Return the repaired object. This becomes db in app.js.
51    End.

53-57 storageFull(error)
53    Decides whether a failed write is "the disk quota is full".
54    No error object means it is not a quota error.
55    Chrome calls it QuotaExceededError. Firefox calls it NS_ERROR_DOM_QUOTA_REACHED.
56    Older browsers use numeric codes 22 or 1014 for the same failure.
57    End. Returns true only for those cases.

59-85 writeSave(store)
59    Writes db to localStorage. Returns "" on success, or a sentence to show
      the user on failure.
60-65 copy is a plain object with only rounds, preflows, settings, and
      lastRoundId. Fields like db.recovered are not written back, so the
      banner does not stick forever. lastRoundId falls back to null.
66    json will hold the string.
67    try to stringify.
68    JSON.stringify walks the whole save.
69-70 If stringify throws (a circular reference, or a value JSON cannot hold),
      return a message telling the user to copy cards out before closing.
      Nothing was written.
71    End of that try.
72    try to write the main key.
73    setItem replaces the previous main save with this string.
74    catch if setItem throws.
75    Quota full: tell the user to export, then delete an old round.
76    Any other write error: a shorter "could not save" line.
77    End of catch.
78    Second try: the backup.
79    Comment: the spare is optional. If only the backup does not fit, the
      round is already in the main key, so this is not a failure.
80    Write the same json under the backup key.
81-82 If that throws, return "" anyway. The main save succeeded.
83    End of backup try.
84    Both writes succeeded. Return "" so the caller shows "Saved in this browser".
85    End.

js/lineup.js  (156 lines)
Puts cards on the page so a response sits on the same horizontal line
as the card it answers, and later cards move down when a line gets tall.
========================================================================

1-14  cardHeight(note, heights)
1     How many pixels tall this card should be.
2     value is a measured height already stored for this note id, if any.
      heights comes from the live textareas in app.js (measurePoints).
3-5   lines, visual, i are working variables.
6     If a real measurement exists and it is at least 40px, use it.
      40 is the minimum card. A smaller number would be a bad measurement.
7     Otherwise estimate from the text: split on newline.
8     visual counts wrapped lines.
9-11  Each source line is at least 1 visual line. About 32 characters fit
      on a card, so a long line counts as ceil(length/32) lines.
12    An empty card still counts as one line.
13    22px per visual line plus 16px of padding, and never under 40.
14    End.

16-32 repliesInColumn(round, parentId, speechId)
16    Every card whose parent is parentId and that lives in speech column speechId.
17    parent is the card being answered. If it is gone, line 22 returns [].
18-21 names, list, i, note.
23-24 Walk every note id.
25    note is that record.
27    Keep it only when three things match: it answers this parent, it is in
      this speech, and it is on the same contention as the parent.
      A same-named column on the other case is a different contention, so it
      is excluded by the contentionId check.
28    Push the match.
30    sortByOrder (rounds.js) orders them by the order field, then by id.
31    End of loop.
32    End of function. Returns the sorted list.

34-35 Comments: a summary card has to clear the rebuttal stack on that line
      or it paints on top of it. After a card has been answered, later speeches
      answer that response. A blank reply box is only drawn on the first speech
      that has not touched the line yet.

36-60 spaceForPoint(round, note, caseSide, heights, saved)
36    How much vertical room this card's whole thread needs.
37-43 own, later, maxStack, s, siblings, stack, i.
44    saved is a cache on note id. If this card was already measured in this
      pass, return that number. Stops infinite recursion on a bad parent loop
      only if the cache was filled; mendRound is what actually breaks loops.
45    own is this card's own height.
46    later is every speech after this one on this case (speechesAfter).
47    maxStack is the tallest pile of replies in any one later column.
48    For each later speech:
49    siblings = replies to this card in that speech.
50    No replies in that column: it does not make the thread taller.
51    stack adds up the space each sibling thread needs.
52-55 Recurse into each sibling. 8px gap between siblings, not after the last.
56    Keep the larger of the stacks. Columns are side by side, so the thread
      is as tall as the tallest column, not the sum of all columns.
58    Cache it. The reserved height is the card itself or the tallest child
      stack, whichever is bigger. That is why a short shell still "holds"
      room for a long rebuttal under it.
59    Return that number.

62-83 placePoint(round, note, top, caseSide, heights, saved, positions)
62    Writes pixel positions. top is where this card's thread starts.
63    own = this card's height (not the reserved thread height).
64    later speeches again.
65-68 loop variables.
69-74 positions[note.id] stores top, the card's own height, the reserved
      thread height, and which speech it is in. The card is drawn at top;
      reserved is what the next shell uses to know where to start.
75    For each later speech:
76    siblings in that column.
77    y starts at the same top as the parent, so the first answer lines up
      with the card it answers.
78-80 Place each sibling at y, then move y down by that sibling's reserved
      space plus 8px.
81-82 End of loops.
83    End. Children of children are placed by the recursive call.

85-94 hasEarlierReply(round, noteId, speechId, caseSide)
85    True if some speech before speechId already has a reply to noteId.
86    list is the speech columns on this case, in order.
87    limit is the index of the speech we are asking about.
88    s is the loop index.
89    Speech is not on this case: treat it as "no earlier reply".
90-91 Walk columns before this one. Any reply there means the line was
      already answered, so a later column should not also grow a blank box
      aimed at the original card.
92-93 End of loop, return false if none were found.

96-155 lineUpGroup(round, contention, caseSide, heights)
96    One contention's layout: positions for real cards, slots for blank
      reply boxes, and the total height of the row.
97    saved caches thread heights for this contention only.
98    positions will be filled by placePoint. It also gets a _threads list.
99    slots will be the blank "Response" boxes.
100   y is the running top of the next shell. Shells stack downward.
101-111 working variables.
112   _threads starts empty. It is not a card id; later code skips this key.
114   For each starting point (a shell: a card with no parent) in order:
115   id of that shell.
116   The note record.
117   If the id is in the list but the note was deleted, skip it.
118   Measure the thread (fills saved).
119   Place the shell and all of its replies, starting at y.
120   threadSpace is the reserved height.
121   Remember this thread's top and reserved height.
122   Next shell starts 8px below this thread.
123   End of shell loop.

125   names = every key now on positions, including "_threads" and every card id.
126   For each key:
127   Skip the _threads bookkeeping key.
128   item is that card's position.
129   later = speeches after the card's own speech.
130   For each later speech:
131   speechId.
132   siblings = real replies already in that column.
133-135 Comment restates the rule: once answered, later speeches answer the
      response. A blank box only goes on the first untouched speech.
135   If this column already has replies, or any earlier column already replied,
      do not add a blank box.
136-140 Otherwise record a slot: which parent, which speech, and the same top
      as the parent card so the box lines up with it.
141-142 End of loops.

144   bottom starts as y, which is just past the last shell.
145-147 A blank box is about 48px tall. If one hangs below the last shell,
      grow bottom so the box is not clipped.
150-154 Return positions, slots, and height (at least 48 so an empty contention
      still has a little room).

js/clean.js  (152 lines)
Turns a Google Docs or Word paste into HTML that is safe to put in a card.
========================================================================

1-2   Comments: keep bold, italic, underline, highlight. Flatten a table or
      an image down to its text. A Word <font color> becomes a span.
      script and iframe are dropped.

4-8   SAFE_TAGS
      An object used as a set. These tag names (uppercase, as node.tagName
      returns them) may be kept: bold, strong, italic, em, underline, strike,
      delete, br, p, div, span, lists, links, mark, sub, sup, blockquote,
      h1-h3, and font. Anything else is unwrapped (its children may survive).

10    SAFE_STYLES
      The only CSS properties copied off a pasted element: color, background
      (the Docs highlight), font size, family, weight, style, underline, align.

12-19 styleIsSafe(value)
12    Rejects a CSS value that could pull in code or a remote resource.
13    lower is the value in lowercase.
14    url( could be a tracking image or a script-bearing resource.
15    expression( is old IE CSS that runs script.
16    javascript anywhere in the value.
17    @import pulls in another stylesheet.
18    Otherwise the value is allowed.
19    End.

21-32 keepStyle(style)
21    Copies only the safe properties off a live CSSStyleDeclaration.
22    out collects "property:value" pieces.
23-24 i, value.
25    No style object: return an empty string.
26    For each name in SAFE_STYLES:
27    Read that property. Inline style only; a stylesheet rule is not here.
28    Skip if the element did not set it.
29    Skip if styleIsSafe says no.
30    Keep "color:#ff0" style text.
31    Join with semicolons. This string is what gets written to the attribute.
32    End.

34-42 keepLink(href)
34    Allows a link only when it is http, https, or mailto.
35    Trimmed string.
36    Lowercased copy, used only for the prefix test.
37-40 Those three prefixes pass the original (not lowercased) value through,

41    Anything else, including javascript: links, becomes "".
42    End.

44-54 cleanInside(node, notice, fragment)
44    Cleans every child of node and appends the safe copies onto fragment.
      notice is an array; cleanTag pushes "simplified" into it when it flattens
      a table or image.
45    child starts at the first child.
46-47 next and cleaned.
48    Loop while a child exists.
49    Remember the next sibling first, because cleaning does not remove the
      original, but the walk must not depend on the copy.
50    cleanTag returns a safe node, a fragment, or null.
51    Only append when there is something to append.
52    Advance.
53-54 End.

56-98 cleanTag(node, notice)
56    Returns a safe copy of one node, or null if it should vanish.
57-61 copy, style, href, text, plain.
62    A text node (nodeType 3) is copied as text. No HTML in it.
63    If it is not an element (nodeType 1), drop it. Comments and the like go.
64    TABLE, IMG, and IMAGE are not cards. They get flattened.
65    Push "simplified" once. indexOf avoids repeating the word.
66    An image has no useful text. A table uses its textContent, which is the
      words in the cells run together.
67    Return a text node, or null if there was nothing to keep.
69    Comment: a citation link is fine. A script or frame is not a card.
70-71 SCRIPT, STYLE, IFRAME, OBJECT are dropped entirely, children included.
      A style block's text is CSS, not evidence, so it is not unwrapped.
73    If the tag is not in SAFE_TAGS:
74-76 Unwrap it. Children are cleaned into a fragment and that fragment is
      returned, so a <table> already handled above never gets here, but a
      <section> or <article> disappears and its paragraphs remain.
78    FONT from Word becomes a span. The color is copied below.
79    H1, H2, H3 become paragraphs so a pasted heading does not blow up the
      card's type size.
80    Any other safe tag is recreated with the lowercase name (b, p, a, ...).
81    style = the filtered inline style.
82-85 FONT's color attribute and size attribute are old HTML, not CSS.
      size is a 1-7 scale; size * 4 + 8 turns it into a rough pixel size.
      Appended onto the style string.
86    If any style survived, set it on the copy.
87    If the copy is a link:
88    href must pass keepLink.
89-93 No safe href: unwrap the link to its text. The words stay, the link goes.
94    A safe href is set.
96    BR has no children. Everything else gets cleanInside.
97    Return the copy.
98    End.

100-111 cleanHtml(html)
100   The function the paste handler calls.
101   notice starts empty. cleanTag may push "simplified".
102   DOMParser reads the paste inside a wrapper div, as a document.
      The wrapper keeps the parser from dropping a bare text node.
103   source is that wrapper, the first element in the body.
104   wrap is an empty div the safe nodes are appended to.
105   If the parser produced the wrapper, clean its children into wrap.
106-110 Return three fields:
      html: the safe inner HTML.
      plain: the same content as text, used for search and for "is this empty?".
      notice: a sentence if anything was simplified, otherwise "".
111   End.

113-124 linesToHtml(text)
113   Plain-text paste has no HTML. This turns newlines into <br> without
      letting the text be read as tags.
114   Split on newline.
115   parts collects escaped lines.
116-117 i, lineBox.
118   For each line:
119-120 Put the line in a div via textContent, which escapes < and &.
121   Take that div's innerHTML, which is the escaped line.
122   Join the lines with <br>.
123-124 End.

126-151 putHtmlHere(html)
126   Inserts HTML at the caret inside the evidence box.
127-132 selection, range, node, parsed, fragment, holder.
133   Nothing to insert: stop.
134   The current selection.
135   No caret: stop. The evidence box should be focused when this runs.
136   The first range.
137   Delete whatever was selected, so paste replaces a selection.
138   Parse the already-cleaned HTML inside a div.
139   An empty fragment to move nodes into.

js/rounds.js  (1064 lines)
Public Forum rules and the shape of a round. No page drawing.
========================================================================

1-10  SPEECHES
      Eight speech ids. Each value has:
        team: "pro" or "con"
        type: constructive, rebuttal, summary, or final
              (type is also the key into the timer settings)
        short: the column header used in print ("Pro Constr.")
        full: the header on the flow ("Pro Constructive")
      Final focus is stored as type "final" and labeled "Pro FF" / "Pro Final Focus".
      Crossfire is not in this map. Crossfire is notes plus a timer step, not a column.

12-18 MARKERS
      The labels a debater can put on a card. id "" is "None", which clears it.
      answered, extend, dropped, turn. The app never assigns these by itself.

20-22 uid(prefix)
20    Builds an id like "note-m1abc-k3f".
21    prefix, then the current time in base 36, then a random integer under
      100000 also in base 36. Two calls in the same millisecond still differ
      because of the random part. Not a UUID, but unique enough for one browser.
22    End.

24-25 Comment: NSDA PF times stored in seconds. 4 constructive, 4 rebuttal,
      3 summary, 2 final focus, 3 and 3 crossfire, 3 grand cross, 3 prep
      per team for the whole round (not per speech).

26-36 timerTimes()
26    The default clock.
27-35 constructive 240, rebuttal 240, summary 180, final 120,
      crossfire 180, grand 180, prep 180. All seconds.
36    End.

38    Comment: the settings boxes are seconds. Typing 4 in constructive is
      treated as "4 minutes", the usual slip.

39-55 pfClock(kind, raw)
39    Checks one settings number before it is stored.
40    n = numeric value. Number("") is 0. Number("abc") is NaN.
41    label starts as the kind name ("constructive", "rebuttal", ...).
42-44 Friendlier words for the message: "final focus", "grand cross", "prep".
45    Not a finite number, or zero or negative: reject.
      Message is "<label> has to be a positive time."
46    Over 20 minutes (1200 seconds): reject. That is not a PF clock.
47    1 through 15: treat as minutes. 4 becomes 240.
      Message tells the user what was saved, e.g.
      "constructive: 4 min saved as 240 seconds."
48-52 That success object: ok, seconds, message.
54    Anything from 16 up to 20 minutes is already seconds. Round to an integer.
      message is "" so the settings page can leave for home.
55    End.

57-69 mendClocks(durations)
57    Repairs a durations object already in a save. Unlike pfClock, this does
      not convert 4 into 240. A stored 4 would be illegal (under the "must be
      a real second count" repair) only if it fails the range check...
      Look carefully:
64    n = Number(stored value).
65    If it is not finite, or <= 0, or over 20 minutes, replace it with the
      default for that key.
66    Otherwise keep it, rounded. So a stored 240 stays 240. A stored 4 stays 4
      because 4 is finite, positive, and under 1200. pfClock is what converts
      minutes at the moment you press Save settings. mendClocks only throws
      out impossible numbers on load.
62    If durations is missing or not an object, return a fresh timerTimes().
63    keys are the seven names.
67    After the loop, return the same object, repaired.
69    End.

71-77 startSettings()
71    The settings object on a brand-new save.
73    fontSize 14 (pixels). The toolbar offers 12, 14, 16, 18.
74    sound false. No beep when a clock hits zero until the user turns it on.
75    durations is a new timerTimes() object.
76-77 End.
